## DIS Image Tester

This is the DIS image tester, a react webapp for experimenting with the DIS image processing settings to turn your actually decent resolution full color album art into the pixelated 2 color message screen.

### How to use

1. Run `npm start` in the `tools/dis_image_tester` directory.
2. Open `http://localhost:5173` in your browser.
3. Add any other images you want to test with to the albumcovers directory.
4. Play with settings etc.
